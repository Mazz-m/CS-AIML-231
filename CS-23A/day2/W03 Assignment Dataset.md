## Glossary

1. **Dataset:** A structured collection of related data points organized into rows and columns so that it can be processed and learned from by a computer model.
2. **GIGO (Garbage In, Garbage Out):** The principle that if flawed, incorrect, or dishonest data is fed into a machine learning algorithm, the output and predictions generated by the AI will also be flawed.
3. **Data Quality:** A measure of how complete, correct, consistent, current, and honest a dataset is, determining its reliability for real-world application and machine training.
